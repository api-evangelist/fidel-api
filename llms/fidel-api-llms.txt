# Fidel API

> Fidel API is a global card-linking platform. One API links Visa, Mastercard and Amex payment cards to web and mobile applications and streams enriched, real-time transaction data (authorization, clearing, refund) from the card networks via webhooks. Used for card-linked loyalty, rewards, and offers. Base URL: https://api.fidel.uk/v1. Authentication: the Fidel-Key API-key header (test and live keys).
